# أتمّ — التزام · تطور · مهام

مقياس شهري لإدارة الذات، يقيس ثلاثة محاور:

- **المهام:** ما تخطّط لإنجازه في الشهر، موزّعًا على مجالات حياتك.
- **التطور:** مهارات تنمّيها بعدد محدّد من التكرارات.
- **الالتزام:** عادات يومية تواظب عليها طوال الشهر.

إعداد وتصميم: **م. إياد حلوبي**

---

## مزايا التطبيق

- عرض للسنة كاملة وعرض لكل شهر، مع حلقات تقدّم ورسم بياني لمسار السنة.
- أيام كل شهر تُحسب تلقائيًا من التقويم، ويُميَّز يوم اليوم في خانات الالتزام.
- صورة ستوري جاهزة للمشاركة (1080 × 1920) لكل شهر وللعام كاملًا، مع إمكانية إضافة صورتك واسمك.
- وضع داكن (الافتراضي) ووضع فاتح.
- نسخة احتياطية في ملف، واستعادة منه، وحفظ بصيغة PDF.
- يعمل دون إنترنت بعد أول زيارة، ويمكن تثبيته على الجوال كتطبيق.

## هيكل الملفات

```
atamm/
```

## الرفع على GitHub

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `atamm`).
2. ارفع محتوى هذا المجلد كما هو، مع الحفاظ على مجلد `public` وملف `render.yaml` في جذر المستودع.

أو من سطر الأوامر:

```bash
git init
git add .
git commit -m "أتمّ — الإصدار الأول"
git branch -M main
git remote add origin https://github.com/USERNAME/atamm.git
git push -u origin main
```

## النشر على Render

**الطريقة الأولى: عبر Blueprint (الأسهل)**

1. من لوحة Render اختر **New → Blueprint**.
2. اربط حساب GitHub واختر المستودع.
3. سيقرأ Render ملف `render.yaml` تلقائيًا وينشئ موقعًا ثابتًا باسم `atamm`. اضغط **Apply**.

**الطريقة الثانية: يدويًا**

1. من لوحة Render اختر **New → Static Site** واختر المستودع.
2. **Build Command:** اتركه فارغًا، أو اكتب `echo "No build step required"`.
3. **Publish Directory:** `public`

بعد النشر يصلك رابط بالشكل `https://atamm.onrender.com`، وكل دفعة (push) جديدة إلى `main` تُنشر تلقائيًا.

## نشر تحديث جديد

1. عدّل `public/index.html`.
2. افتح `public/sw.js` وغيّر رقم الإصدار في السطر:
   ```js
   const VERSION = "atamm-v1";   // ← مثلًا: atamm-v2
   ```
   هذا يضمن أن يحصل المستخدمون على النسخة الجديدة بدل النسخة المحفوظة على أجهزتهم.
3. ارفع التعديل إلى GitHub، وسينشره Render تلقائيًا.

## تشغيله على جهازك

افتح `public/index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا (لتجربة التثبيت والعمل دون إنترنت):

```bash
npx serve public
```

## ملاحظة مهمة عن البيانات

- تُحفظ بيانات كل مستخدم **في متصفحه فقط** (localStorage)، ولا تُرسل إلى أي خادم.
- البيانات مرتبطة بالرابط وبالمتصفح، فلو انتقلت من الملف المحلي إلى رابط Render، أو من جهاز إلى آخر، فلن تنتقل البيانات تلقائيًا.
  **لنقلها:** من قائمة النقاط الثلاث اختر «نسخة احتياطية» في المكان القديم، ثم «استعادة من ملف» في المكان الجديد.
- عندما يحين وقت أخذ نسخة احتياطية تظهر نقطة حمراء على زر القائمة.
